About this dashboard

Mockup status: static HTML with hard-coded mock data. Real implementation per planning/29_Dashboard_Spec_2026-04-25.md · scaffolded as lub.dashboard module. Live version reads lub.ledger sqlite directly via tiny FastAPI server (lub-dashboard --port 8081) and renders the same panels with real data.

Petition narrative posture: per ADR-002, this dashboard is positioned as the calibrated-observability layer for ruflo-orchestrated agent swarms. It does not change the 4 first-and-only claims — it makes them visible.

Upstream contribution candidate: answers ruvnet/ruflo issue #1328 ("web visualization board") — could be PR'd as lub-ruflo-dashboard-pack.
