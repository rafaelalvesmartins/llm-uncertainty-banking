Manage

  • Refusal policy. Answers whose estimator confidence falls below the configured refusal threshold are withheld rather than returned. The refusal AUROC above measures how well confidence separates correct from incorrect answers — values near 0.5 indicate the refusal gate is not informative and should not be relied on.
  • Change management. Any change to backend, estimator, refusal threshold, or calibration dataset invalidates the evidence in this report and requires a fresh run.
  • Incident handling. Material miscalibration (e.g. ECE above an institutionally set tolerance) should be triaged as a model-risk finding, not a latent feature request.
