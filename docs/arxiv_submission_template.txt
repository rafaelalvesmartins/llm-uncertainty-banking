**Abstract:**

Large language models are increasingly embedded in banking workflows where hallucinations
carry supervisory and financial-stability consequences. We present llm-uncertainty-banking (LUB),
an open-source Python framework unifying 22 UQ estimators across seven families, evaluated on
financial regulatory text in English and Portuguese. We report 14 calibration metrics and
introduce a multi-regime regulatory crosswalk mapping benchmark outputs to six regimes
(NIST AI 600-1 GenAI Profile of AI RMF 1.0, EU AI Act 2024/1689, BCBS 239, BCB Res. 4.893,
ISO/IEC 23894:2023, ISO/IEC 42001:2023; SR 11-7 three-pillar mapping cross-referenced),
producing OSCAL Component Definitions and auditor-readable reports. We additionally release
a thin governance layer (input/output rails inspired by NeMo Guardrails, uncertainty-gated
policies inspired by Guardrails AI) that closes the loop from uncertainty scores to MANAGE-section
actions in the generated report. Code, datasets, and reproducibility artifacts are released
under Apache 2.0.

**Key contributions (no existing OSS tool combines these):**

1. First OSS library to emit OSCAL Assessment Results (validated against NIST JSON schema)
   for LLM evaluations. Prior work: Venturalítica SDK (Cilla Ugarte et al. 2026,
   arXiv:2604.13767v1) produces OSCAL but explicitly limits scope to tabular and medical
   imaging; UQLM (CVS Health, JMLR 2026), LM-Polygraph — none ship OSCAL output
2. First OSS LLM UQ library mapping outputs to SR 11-7 model-validation pillars and NIST
   AI 600-1 MEASURE 2.3 / 2.7 / 2.9. ValidMind advertises SR 11-7 evidence but is
   closed-source and not LLM-UQ-native
3. First OSS library combining conformal prediction for LLMs (5 variants: split, adaptive,
   Mondrian, sampling, CCP) with calibration reporting in a single auditable artifact
4. First UQ benchmark targeting financial regulatory text, with 8 datasets including novel
   Brazilian regulatory QA curated from BCB/CMN public sources
5. Thin governance layer (no DSL, no async, no bundled jailbreak ML) that feeds uncertainty
   scores directly into AI RMF MANAGE-section action items

**Evaluation:**

- **Datasets:** FinQA, ConvFinQA, TAT-QA, BR-Regulatory (novel), German Credit, Australian
  Credit, FPB, FiQA-SA
- **Metrics:** 14 calibration metrics (ECE, RMSCE, ENCE, Brier, refusal AUROC, etc.),
  5 proper scoring rules, UCC/AUUCC curves
- **Backends tested:** HuggingFace (Qwen, Mistral, Llama), OpenAI (GPT-4), Anthropic (Claude)
- **Results:** Semantic entropy dominates on multi-hop financial QA; conformal methods provide
  distribution-free coverage guarantees relevant to SR 11-7

**Artifact availability:**

- **Code:** https://github.com/user/llm-uncertainty-banking (Apache 2.0)
- **Datasets:** Included in repo; BR-Regulatory is newly curated from public BCB/CMN sources
- **Notebooks:** Reproducibility walkthroughs for all benchmarks
- **Documentation:** Complete API docs, deployment patterns, governance patterns

**Related concurrent work:**

This work complements recent papers on LLM calibration (Kuhn et al. 2023 on semantic entropy,
Band et al. 2024 on linguistic calibration) and extends conformal prediction methods to language
(Quach et al. 2024) by providing a unified benchmarking framework and regulatory compliance
outputs.
